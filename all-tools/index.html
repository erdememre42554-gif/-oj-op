How to read this table

“Runs with” names the actual browser primitives and libraries the tool uses. If a tool needed a server, it would be listed here as a network call — none of the twenty do. The three categories exist because strings, randomness and calendar arithmetic fail in different ways, not because the layout needed three columns.

  • Text & words — Count, clean, sort and reshape text. These tools run on the string you paste, in the tab, with no round trip to a server.
  • Codes & generators — Create passwords, passphrases, QR codes and barcodes using Web Crypto and local encoders. The output is never transmitted.
  • Converters & calculators — Convert units, work out percentages, compare dates and model a loan. Every formula is deterministic and stated on the page.
