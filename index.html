    Scene 07 — the claim, demonstrated

    A password that never leaves this device.

    Every character below comes from crypto.getRandomValues, not Math.random. The value exists in this tab's memory and nowhere else — there is no endpoint that could receive it.

    Open DevTools → Network before pressing generate. You will see no request, because the generator is a function call, not a form submission.
